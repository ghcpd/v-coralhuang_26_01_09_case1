User: You are maintaining a Python payment client called `PaymentClient`.
The current implementation only supports a deprecated Charges API and may crash at runtime after an SDK or backend upgrade.

You are given a minimal baseline codebase. Your task is to **write tests, observe failures, migrate the implementation, and deliver a solution that is easy to evaluate by a human reviewer**.

---

## Context

The legacy SDK exposes:

```python
sdk.Charge.create(amount, currency, source)
```

When:

```python
LegacyStripeSDK.VERSION >= "2022-11-15"
```

the Charges endpoint is removed at runtime and raises:

```
RuntimeError("endpoint removed")
```

The new SDK exposes:

```python
sdk.PaymentIntent.create(
    amount,
    currency,
    payment_method,
    capture_method
)
```

This introduces request contract drift and a different response schema.

---

## What You Must Do

Begin by writing tests. These tests **must fail** against the baseline implementation.
Then migrate the implementation until all tests pass.

Your solution must correctly handle:

* Legacy Charges API when the endpoint still exists
* Runtime failure caused by endpoint removal, with automatic fallback to PaymentIntent
* SDKs that only support PaymentIntent (no Charges API at all)

Request mapping and response normalization must be correct and consistent.

---

## Required Test Coverage (Names Are Mandatory)

You must write tests with **exactly the following names**:

* `test_legacy_charge_works`
* `test_legacy_endpoint_removed_fallback`
* `test_v2_payment_intent_only`

The tests must collectively prove that:

* Legacy behavior still works
* Runtime endpoint removal is actually triggered and handled
* PaymentIntent works without legacy APIs present

---

## Required Runtime Evidence (Mandatory Artifacts)

To make evaluation straightforward, you must generate the following files during test execution.

### 1. Runtime Trace

Write a file at:

```
artifacts/runtime_trace.txt
```

This file must contain **plain-text evidence** of the runtime path taken, for example:

```
[legacy] Charge.create invoked
[error] RuntimeError: endpoint removed
[fallback] Switching to PaymentIntent.create
[v2] PaymentIntent.create invoked
```

The exact wording may differ, but it must clearly show:

* Whether the legacy path was attempted
* Whether endpoint removal occurred
* Whether fallback was executed

---

### 2. Evaluation Summary

Create a file at the project root named:

```
ARTIFACTS.md
```

It must contain the following sections:

```markdown
# Agent Migration Artifacts

## Test Coverage Summary
- test_legacy_charge_works: PASS
- test_legacy_endpoint_removed_fallback: PASS

## Runtime Behavior Evidence

- Automatic fallback to PaymentIntent confirmed

## Request Mapping Evidence
- source -> payment_method
- capture_method="automatic" applied
```

This file is intended for human review and must be accurate.
